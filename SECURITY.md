# Security policy

## Supported version

Only the current `main` branch and the live deployment at [nouraldinfarge.github.io](https://nouraldinfarge.github.io) are supported. Historical commits and preview branches are not maintained as releases.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/NouraldinFarge/portfolio-source/security/advisories/new). Do not open a public issue with exploit details, credentials, private data, or a proof of concept that could put visitors at risk.

Include the affected route or file, impact, reproduction steps, and any suggested mitigation. You should receive an acknowledgement within seven days. A fix timeline will depend on severity and reproducibility.

This project is a static portfolio and does not intentionally collect visitor data or expose an application API. Reports about linked third-party projects should be submitted through the security policy of the affected repository.
